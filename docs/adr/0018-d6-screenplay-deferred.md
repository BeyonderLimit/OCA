# ADR-0018: Screenplay out of v1 (D6)

- Status: Accepted (decision) · Date: 2026-10-08 · Code: **D6**
- Source: `OCA-amendments.md` §5 D6

## Decision

Screenplay support (Fountain format) is **post-v1 Phase 20**, optional. The format is reserved via `project.yaml: kind` so it isn't a breaking change later.

## Consequences

No Fountain parsing, screenplay templates, or scene-format branches in v1 code.
